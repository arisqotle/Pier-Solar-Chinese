# Pier Solar（太阳码头）简体中文汉化

本项目致力于为 Mega Drive / Genesis 平台角色扮演游戏 **Pier Solar and the Great Architects** 提供自然、易读、忠于原作的简体中文体验。汉化不仅是将英文替换成中文，也需要在主机原有的显示条件下兼顾文字表达、版面效果和程序稳定性。

## 汉化范围与特色

游戏中的剧情对话、人物交流、菜单选项、道具与魔法说明、商店及战斗提示、地点名称等，均属于汉化工作的主要范围。必要时会调整中文字库、换行、行距、颜色及其他与文字显示直接相关的排版细节，尽量保留原本的界面结构与游戏风格。

- **译文反复校对。** 结合剧情语境、人物身份和实际画面推敲词句，避免生硬直译；统一人名、地名、称谓、术语及中文标点，尽量让文字自然、准确且前后一致。
- **以阅读体验为重。** 对话使用更醒目的字体；对于菜单等空间有限的界面，不满足于仅仅「能显示中文」，还希望字号、笔画、对齐和层次都适合实际游玩。
- **尊重原作。** 汉化改动仅限文字、字库及其必要的显示适配；不主动修改剧情、关卡、数值、人物移动速度、遇敌率、战斗规则和其他游戏机制。
- **不添加私货与广告。** 不加入额外剧情、个人观点、推广信息、内置作弊功能或金手指，也不通过篡改原制作名单来添加汉化署名。
- **保留语言选择。** 汉化目标为英文与简体中文两种语言，兼顾原作体验和对照需求。

## 为什么选择 Reprint A

《Pier Solar》存在不同发行和再版 ROM，文件大小相同并不意味着内部文本、资源位置及程序布局完全一致。若在多个版本之间混用地址、字体或对话数据，可能导致文字错位，甚至产生难以追踪的问题。

本项目在前期对不同版本进行比较后，选定以下版本作为**唯一固定开发与对照基底**：

`Pier Solar and the Great Architects (World) (En,Fr,De) (Reprint A) (Aftermarket) (Unl)`

选择这一版本的重点不是声称它在所有再版中「最好」，而是使文本提取、地址定位、修改前后比较以及实际回归测试都有统一参照。固定基底有利于核查哪些差异确实来自汉化，哪些是原版已有的行为。其他版本不能直接视为补丁兼容对象。

## 关于中文字体：不只追求放得下

原版的部分英文菜单文字采用约 **8 像素高度**的字体。英文字符笔画相对简单，压缩后仍有一定可读性；中文汉字却包含更多横竖、转折和内部留白。若直接用同样高度的 8 像素点阵显示中文，复杂汉字很容易笔画挤在一起，阅读费力，整体观感也不够美观。

因此，本项目对这类**小字号菜单中文**采用**将原约 8 像素高度的英文小字，改为约 9 像素高度的中文字形**的设计方向：在尽量维持原有菜单框尺寸的前提下，给汉字笔画多留一点空间。这个变化看起来只有 1 像素，但对于汉字清晰度和整体美观都有意义。具体界面仍需逐一验证，不能将设计目标等同于所有画面均已完成替换；剧情对话等区域仍优先保持较大的文字。字号并非越大越好，必须综合原有菜单框大小、行数、按钮位置和实际显示效果决定，不能简单把所有文字统一放大。

## 为什么汉化并不只是替换文字

如果完全沿用原版的字号、字符宽度和布局，只在既有位置替换相应字形，改动相对集中，也比较容易控制由汉化引入的问题。但这种做法未必适合中文：一个复杂汉字往往不能像英文字母那样在很小的像素范围内清晰显示，直接照搬原有排版也容易出现拥挤、换行不自然的现象。

一旦调整字符高度、宽度、字间距、行距或文字位置，问题就不再局限于字库本身。游戏中的菜单框、光标、高亮区域、行数计算、文字绘制与清除、图块缓存、不同画面的共用显示流程，都可能受到影响。例如，某处看似只多出一行像素，却可能让另一个界面的文字重叠、残留或闪烁。此外，文字位图可能与图块更新、绘制顺序及内存缓冲区存在关联。部分异常还具有场景相关性，不一定能在修改后立即发现。也正因为如此，表面上只是将小字提高 1 像素，实际排查工作可能远超过直接替换文字。

因此，项目采用反复对照、修改和实机／模拟器测试的方式：不仅检查中文能否正确显示，还要尽量确认字体及排版适配没有破坏原有操作流程和显示逻辑。**提高中文可读性，与避免引入新问题，需要同时兼顾。**

## 哪些内容保留原文

这里的「汉化」并不等于把 ROM 中出现的每一个英文字符都翻成中文。以下内容原则上保留原文：

- **HP、MP、PP 等通用状态缩写及必要的短标识**：这些标记简洁、辨识度高，部分界面还受固定空间限制，强行改成中文未必更好。
- **制作名单中的人名、品牌、网站地址、版权和商标信息**：属于应予尊重的原始署名与专有信息，不随意改写；包含重音符号的人名也尽量保持原貌。
- **部分专有名称、技术标记及英文界面标签**：在需要保持识别准确性、兼容性或原作界面风格时保留；是否翻译依据具体语境决定。
- **英文语言选项中的原文内容**：保留英文模式供玩家选择和对照。

对话和剧情中的专有称谓仍会结合语境处理，不能把「保留专有信息」误解成所有英文名称一律不汉化。

## 发布说明

项目仍处于文字、排版和运行质量核验阶段。确认符合发布要求后，计划通过 GitHub Releases 提供**差分汉化补丁**、使用说明与适配文件校验信息，不提供完整游戏 ROM。

上述内容说明项目的设计取向和实施原则；最终发行结果仍以实际补丁、原版对照和回归验证为准。
