# Pier Solar 简体中文汉化

Mega Drive / Genesis 游戏《Pier Solar and the Great Architects》社区汉化项目。

**状态：开发与回归测试中，尚未发布正式补丁。**

## 目标版本
`Pier Solar and the Great Architects (World) (En,Fr,De) (Reprint A) (Aftermarket) (Unl)`

目标是提供 English / Chinese 两种语言选项，汉化对话与菜单、优化中文字体显示，尽量不改变原版逻辑、数值与流程。

## 发布计划
待汉化相关代码与显示问题回归完成后，计划发布差分补丁及其使用说明与校验值，而不是完整游戏 ROM。当前没有可以下载的正式发行版。

本项目为非官方社区汉化工程。游戏、商标、图像和音频权利归各自权利人；本仓库不附带商业游戏 ROM。
