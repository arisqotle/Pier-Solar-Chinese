# 《太阳码头》简体中文汉化 · v1.0

**Pier Solar and the Great Architects · Mega Drive / Genesis**

> 非官方、免费汉化补丁。以原版 Reprint A 为基础，不提供游戏 ROM。

《太阳码头》（Pier Solar and the Great Architects）是 WaterMelon 于 2010 年推出的世嘉 MD 原创角色扮演游戏。游戏容量为 **64Mb（8MB）**，拥有丰富的剧情、精美的画面和音乐，以及传统的回合制战斗系统，是 MD 后期原创游戏中颇具代表性的一部作品。

本次汉化涵盖剧情对白、战斗提示、道具说明、魔法、商店、菜单等内容，译文和排版均经过多轮校对。

## 汉化特色

- **重制中文字库与菜单排版。** 原版部分英文菜单文字仅约 8 像素高。直接换成同等高度的汉字虽较简单，但不易辨认、观感也不理想。因此针对部分菜单使用约 **9～10 像素高度**的中文字形，重新调整字距、换行、对齐和界面布局。
- **反复排查显示与性能问题。** 字体及布局修改牵涉多套绘字流程，曾引发乱码、闪烁、光标错位、响应延迟等问题。大部分开发精力用于这些兼容问题的修复、测试与优化，而不只是翻译文字。
- **兼顾六键手柄操作。** 对原版在部分设备上 X／Y／Z 魔法快捷键失效的六键读取兼容问题进行了修复，保留原有快捷键与施法规则。具体效果仍取决于设备及手柄配置。
- **尽量忠于原版。** 不修改剧情、战斗难度、经验、金钱、遇敌等游戏设定；不加入广告、推广信息或无关内容。原制作团队的署名、品牌、商标与版权信息保留原文。部分属性缩写和不适合汉化的标识仍使用英文。
- **免费发布。** 仅供个人学习、交流及非商业用途。

## 下载与使用

请从本项目的 **[Releases](../../releases)** 获取 `Pier_Solar_CN_Patch_v1.0.zip`，解压得到 `.bps` 汉化补丁及说明文件。补丁**不包含完整游戏 ROM**。

本补丁仅适用于：

`Pier Solar and the Great Architects (World) (En,Fr,De) (Reprint A) (Aftermarket) (Unl)`

| 校验项 | 所需原版 ROM | 打补丁后 ROM |
| --- | --- | --- |
| 文件大小 | 8,388,608 字节 | 8,388,608 字节 |
| CRC32 | `25B7063E` | `EFB553E6` |
| MD5 | `a9e1c602105aaeb9df2ab82a1ea9a832` | `f4dd8ee011a527f492ee79da112a5553` |
| SHA-256 | `f2dbd13177226552eefe1f96fb31366b04f80d256a1e684d3263ad8719f3eb6e` | `a6af606f0d13a18294217323fb8648bb72df4838fb5ef921d67d784ffbb54a75` |

使用 [Floating IPS（Flips）](https://github.com/Sir-Walrus/Flips/releases)：

1. 运行 Flips，选择 **Apply Patch**。
2. 选择解压后的 `.bps` 文件。
3. 选择校验值匹配的 Reprint A 原版 ROM。
4. 选择输出位置并保存，使用上表校验输出文件。

请勿对其他再版、交错编码或带额外文件头的 ROM 强行应用补丁。

## 关于 v1.0 与后续更新

**v1.0 是首次公开发布版本，并非未经验证的初版。** 在此之前，汉化已经经历大量反复修改、测试、校对与优化，且已完成全流程通关测试。

因此，若后续没有发现**影响正常游玩体验的 BUG**，原则上将不再持续推出新版本；必要的严重问题仍会评估修复。欢迎在 [Issues](../../issues) 或发布帖留言反馈，最好附上使用平台、复现步骤、截图及存档。

## 版本选择与说明

本项目固定以 MD **Reprint A** 为开发和对照基础，目的是让文字、程序地址、资源和测试结果保持一致；这并不意味着其他再版一定更差。不同再版不保证补丁兼容。

保留的英文包括 HP／MP 等常见属性缩写、原开发者署名、品牌、商标、网址及版权内容，以及部分受空间和显示规则限制的标识。这些并非全部属于汉化遗漏。
