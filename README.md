# Pier Solar（太阳码头）简体中文汉化

本项目致力于为 Mega Drive / Genesis 平台的角色扮演游戏 **Pier Solar and the Great Architects** 提供完整、自然、忠于原作的简体中文体验。

## 汉化内容

汉化工作围绕游戏内文本及其显示展开，包括剧情对话、人物交流、菜单选项、道具和魔法说明、商店及战斗提示、地点名称，以及其他与玩家理解游戏有关的文字内容。针对原版英文显示空间与中文字形不同的问题，对必要的字体、换行、颜色及排版作相应适配。

## 项目特色

**以原作内容为准。** 译文不追求机械直译，而是结合角色身份、故事语境及实际游戏画面反复校对、推敲，尽量做到意思准确、表达自然、名称与术语前后一致。

**尽量保持原汁原味。** 项目坚持只对汉化所必需的文本、字库和显示适配进行修改，不主动更改剧情、关卡、人物属性、经验和金钱、移动速度、遇敌率、战斗规则及其他原版游戏机制。

**不添加私货。** 汉化不加入额外剧情、个人观点、广告、商业推广信息、破解功能或金手指，也不通过替换原制作人员信息来增加汉化署名。原有品牌、版权及相关制作信息以尊重原作为原则。

**重视文字与运行质量。** 除了中文是否通顺，还反复核对文字显示、菜单操作、语言切换及游戏流程，尽量避免因汉化而产生新的问题。

**保留语言选择。** 计划保留英文与中文两种语言选项，便于按需游玩及对照原作。

## 游戏版本

适配基底为：

`Pier Solar and the Great Architects (World) (En,Fr,De) (Reprint A) (Aftermarket) (Unl)`

其他再版及不同发行版本不应默认视为兼容，实际适配请以后续补丁说明为准。

## 发布说明

项目目前处于汉化整理与质量核验阶段。完成必要验证后，计划公开发布**差分汉化补丁**及使用说明、校验信息，不提供完整游戏 ROM。

上述内容描述项目的工作原则和目标；最终发布前仍会以原版对照和实际测试结果确认其实现情况。
